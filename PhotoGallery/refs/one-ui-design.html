PhotoGallery One UI 제품 디자인 계약

TV/large-screen Tizen에서 실제 미디어 라이브러리의 사진을 차분하게 찾고, 확인하고, 안전하게 관리하는 Gallery 경험이다. Galaxy Gallery의 content-first hierarchy와 One UI의 명확한 destructive feedback을 참고하되 proprietary asset·screen copy는 사용하지 않는다.

기존 참조 보존: photo-gallery-design.html은 adoption 전부터 있던 visual exploration으로 그대로 남긴다. 이 문서는 그것의 Pictures/Albums/detail 방향을 검토해 제품 상태, privacy, focus, real-media boundary, acceptance까지 확장한 구현 전 계약이다. 기존 문서의 외부 stock 이미지 URL은 제품 runtime asset이 아니다.

1. 목표, 대상 사용자, 비목표

목표

  • 실제 Tizen MediaContent 사진을 날짜순 grid와 검색으로 발견한다.
  • 선택한 사진의 상세/metadata를 보고 삭제 전 명확하게 확인한다.
  • 사람과 Agent 모두 안정 Photo ID로 같은 현재 문맥을 다시 찾는다.

대상과 비목표

  • remote/D-pad 중심 TV 사용자, keyboard·pointer·touch도 동등 지원한다.
  • 편집·클라우드·얼굴 인식·공유 계정·static media demo는 이번 범위 밖이다.
  • 미디어 capability/권한이 없으면 실제 기능을 흉내 내지 않고 unavailable 상태를 보인다.

4. Interaction, focus, accessibility

입력규칙검증 postcondition
Remote/D-pad초기 focus는 첫 visible photo 또는 Retry. Up/Down/Left/Right는 spatial card order; Enter는 detail/command; visible focus ring은 accent+inner contrast double ring.각 이동 뒤 annotated focused card가 바뀌고 screenshot으로 cue가 보인다.
KeyboardTab/Arrow navigation, Enter activation, Escape/Back cancel. Search text는 input에만 전달한다.Search 입력·clear와 focus restoration을 확인한다.
Pointer/touchcard tap/click은 같은 semantic command를 dispatch하고 focus를 clicked actor에 부여한다. hover만으로 selection을 mutation하지 않는다.detail transition 후 matching photo ID가 유지된다.
ModalDelete overlay는 Cancel/Delete만 focus trap; initial focus는 Cancel; Back은 Cancel; 성공 시 overlay 제거와 next card focus.실제 Delete Action failure는 overlay가 남고 error label이 보인다.

Visual tokens

  • canvas: 1920×1080, full physical root + centered uniform ancestor scale.
  • paper #f7f7f8, ink #17181c, accent/focus #e9524b.
  • cards 16–24 design-unit radius, 8–24 spacing scale; typography and border도 transform 한 번만 적용.
  • 색만으로 selected/error를 구분하지 않는다.

Accessible content

  • card label: title/date + position; thumbnail 자체를 유일한 의미 전달로 쓰지 않는다.
  • metadata는 길이를 제한하고 ellipsis/full accessible label을 제공한다.
  • 삭제 confirmation은 대상 식별자와 결과를 spoken/visible status로 제공한다.
  • Path, private note, precise location은 privacy policy 확인 전 노출하지 않는다.

6. Responsive and lifecycle policy

  • Window.Default.WindowSize와 GetInsets()의 drawable area에서 scale=min(width/1920,height/1080), centered offset을 계산한다.
  • zero/negative/inset-exhausted geometry에는 current root를 버리지 않는다. valid viewport일 때만 replace한다.
  • scan, search, thumbnail decode는 UI thread에서 수행하지 않는다. 새 intent/pause/terminate는 cancellation token을 cancel하고 late completion은 sequence gate가 폐기한다.
  • 현재 rendered photo만 finite positive measured bounds와 함께 publish한다. paused, detail close, modal changes, focus change, dispose 때 snapshot을 갱신한다.
